# Sales Prediction Using Python

## Overview
This project predicts sales using Machine Learning techniques in Python. It analyzes advertising expenditure data and estimates future sales based on input features.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Sales prediction
- Performance evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The dataset contains advertising expenses across different media channels such as:
- TV
- Radio
- Newspaper

Target Variable:
- Sales

## Project Workflow
1. Import dataset
2. Data preprocessing
3. Exploratory Data Analysis
4. Train-Test Split
5. Model Training
6. Prediction
7. Model Evaluation
